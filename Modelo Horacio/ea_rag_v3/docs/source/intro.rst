Introducción
============

Propósito
---------

El sistema **EA RAG v3** combina inteligencia artificial y consultas estructuradas
para gestionar y analizar el **personal militar argentino**.

Objetivos principales
---------------------

- Proveer una interfaz accesible en **lenguaje natural**.
- Garantizar resultados consistentes con consultas estructuradas.
- Asegurar **trazabilidad y auditoría** completa.
- Preparar la arquitectura para **escalabilidad en cloud**.
